When transmitted across the target channel, the client station immediately tears down its internal link state, disconnecting from the local network within milliseconds. 6.3 The 4-Way WPA2 Handshake Capture Pipeline Deauthentication attacks are rarely deployed merely for transient network disruption; their primary operational value in penetration testing is forcing target client devices to reconnect to the network, thereby generating the critical **4-Way EAPOL Handshake**. When a client reconnects to an access point using WPA2-PSK, the two entities establish mutual cryptographic trust and derive transient session keys without transmitting the master pre-shared key (PSK) across the air. The authentication exchange proceeds across four sequential EAPOL (Extensible Authentication Protocol over LAN) frames: 1. Message 1: The AP generates a cryptographically secure random number, the Anonce, and transmits it to the client. 2. Message 2: The client generates its own random number, the Snonce. Using the Anonce, Snonce, its own MAC address, the AP's MAC address, and the secret Pairwise Master Key (PMK derived from the network password via PBKDF2), the client calculates the Pairwise Transient Key (PTK). It transmits the Snonce to the AP alongside a Message Integrity Code (MIC) computed over the frame. 3. Message 3: The AP verifies the MIC, derives the PTK, and sends the encrypted Group Temporal Key (GTK) to the client. 4. Message 4: The client confirms receipt of the keys. By capturing Messages 1 and 2 in an active PCAP file, an auditor acquires all parameters required to execute an offline dictionary attack against the MIC, recovering the plaintext Wi-Fi password without ever interacting with the access point again. 6.4 Firmware Hardening, Antenna Propagation, and RF Forensics Mitigating wireless injection attacks requires deploying IEEE 802.11w Protected Management Frames (PMF), which append a cryptographic message integrity code (BIP-CMAC-128) to all management frames, causing clients to reject forged deauthentication packets.
